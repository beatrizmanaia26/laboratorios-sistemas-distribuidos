# Padrão Request-Reply com ZeroMQ

Implemente um gerenciador de tarefas usando o padrão request-reply de forma que o cliente é responsável pela interação com o usuário e o servidor faz o armazenamento e recuperação dos dados do cliente. O programa deve:
- Usar containers para a execução (use o que está na pasta `src/broker` como base)
- Permitir adicionar, remover e listar tarefas

Devem ser entregues os arquivos `Dockerfile`, `docker-compose.yaml`, `cliente.py`, `servidor.py`, `broker.py` em um zip. **A entrega é individual.**
